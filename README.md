### 1. Clonar el repositorio
Abre una terminal y ejecuta el siguiente comando para descargar el proyecto:
```bash
git clone https://github.com/TomasLena/mejor-proveedor.git
cd tu-repositorio
```

### 2. Iniciar el Backend
En la primera terminal, entra a la carpeta del servidor, instala las dependencias y prendelo:
```bash
cd backend
npm install
npm run dev
```

### 3. Iniciar el Frontend
Abre una **segunda terminal** (sin cerrar la anterior), entra a la carpeta del cliente, instala las dependencias y prendelo:
```bash
cd frontend
npm install
npm run dev
```

---
Una vez que ambas terminales estén corriendo, abre tu navegador en la dirección que te indique la terminal del frontend `http://localhost:3000/`
